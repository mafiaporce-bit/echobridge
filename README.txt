EchoBridge v3 - deploy to Netlify
1. Go to app.netlify.com and sign in.
2. Sites > Add new site > Deploy manually (or open your existing EchoBridge site > Deploys).
3. Drag this whole folder onto the page. Dropping it on an existing site replaces the old version.
4. Open the link in Chrome on the tablet, tap the menu > "Add to Home screen".
5. If the tablet still shows the old version, close the app fully and open it again (it refreshes itself on the next start).
Grown-up corner PIN starts as 1234 (change it in Lock & data).
